# Program Analytics Portfolio

Welcome to my portfolio showcasing projects at the intersection of **Data Analytics, Monitoring & Evaluation (M&E), and Program Management**.

My work focuses on transforming program data into actionable insights to support evidence-based decisions, improve data quality, monitor performance, and strengthen program implementation.

## Areas of Focus

- **Data Analytics:** Data cleaning, validation, exploratory analysis, and visualization.
- **Monitoring & Evaluation:** Indicator tracking, outcome analysis, and results measurement.
- **Program Management:** KPI monitoring, progress tracking, forecasting, and decision support.
- **Data Management:** Data reconciliation, database quality assurance, and geospatial data integration.

## Featured Projects

### 1. Cooperative Data Reconciliation & GIS

A data quality and reconciliation project designed to identify inconsistencies between cooperative membership records and farm mapping data.

**Planned tools:** Excel, Power Query, Python, SQL, and QGIS.

**Key outputs:** Data quality assessment, record matching, reconciliation summary, and decision-support dashboard.

*Status: In progress.*
